# AI Content Generation — Lexical Editor Feature

**Date:** 2026-05-20  
**Status:** Implemented  
**Collections:** Posts, Pages, Portfolio, Job Vacancies (and any Global with a Lexical rich-text field)

---

## Overview

A Notion AI–style content generation panel embedded directly in the Payload Lexical rich-text editor toolbar. Editors can draft new content, expand passages, rewrite sections, or summarize selected text — all without leaving the editor. Output is SEO-optimized and humanized to avoid AI detection signals.

---

## Architecture

```
Toolbar button click (fixed or inline/selection toolbar)
  → reads current selection text
  → dispatches OPEN_AI_PANEL_COMMAND (Lexical command)
  → AiContentPlugin (position: 'top') toggles panel open/closed
  → user picks action tab + types prompt
  → POST /api/seo/generate-content
  → Claude API (claude-sonnet-4-6) + humanize()
  → preview shown in panel
  → Accept → insertMarkdownContent() → Lexical nodes inserted at cursor
```

Custom Lexical feature uses Payload's server/client split:

- **Server file** (`feature.server.ts`): declares the feature key + points to client component path
- **Client file** (`feature.client.ts`): registers toolbar button + top-position plugin via `createClientFeature`
- **importMap**: auto-regenerated by `npm run generate:importmap`

## Panel States

1. **Ready** — action tabs + prompt textarea + collapsible tips + ✨ Generate button
2. **Generating** — prompt locked, animated dots, Cancel button, "Still generating…" after 8s
3. **Preview** — generated text in a scrollable box + Accept / ↺ Regenerate / Discard

---

## Actions

| Action | What it does | Requires selection |
|--------|-------------|-------------------|
| **Draft** | Writes new content from a prompt | No |
| **Expand** | Expands selected passage with more detail | Yes |
| **Rewrite** | Rewrites selection with new tone/style | Yes |
| **Summarize** | Summarizes selected passage in 2-4 sentences | Yes |

For Expand/Rewrite/Summarize: if no text is selected when the button is clicked, the panel shows a warning banner and disables Generate until the user selects text and clicks ✨ AI again.

---

## Toolbar Button

The button appears in **both** the fixed toolbar (always visible) and the inline toolbar (appears on text selection). Styled to blend with existing toolbar buttons — `✨ AI` text with a subtle background.

On click:
1. Reads the current selection text from the editor state
2. Dispatches `OPEN_AI_PANEL_COMMAND` with the selection as payload (or `null` if nothing selected)
3. Panel opens and pre-selects "Expand" if text was selected, "Draft" otherwise

---

## Content Insertion

On Accept, the plugin:
1. Parses the generated markdown into Lexical nodes:
   - `## heading` → `HeadingNode('h2')`
   - `### heading` → `HeadingNode('h3')`
   - `- item` → `ParagraphNode` with `• ` prefix
   - `**bold**` → `TextNode` with bold format
   - other lines → `ParagraphNode`
2. For **Draft**: inserts nodes at the current cursor position
3. For **Expand/Rewrite/Summarize**: removes the selected text, then inserts new nodes in its place

## API Route — `POST /api/seo/generate-content`

### Request

```json
{
  "action": "draft" | "expand" | "rewrite" | "summarize",
  "prompt": "string",
  "selectedText": "string (optional, max 4000 chars)",
  "collectionSlug": "string (optional)",
  "docId": "string (optional)",
  "locale": "en" | "id"
}
```

### Response

```json
{ "value": "generated markdown string" }
```

### Validation

| Condition | Status |
|-----------|--------|
| `ANTHROPIC_API_KEY` missing | 503 |
| `action` not in allowed list | 400 |
| Draft with no `prompt` | 400 |
| Expand/Rewrite/Summarize with no `selectedText` | 400 |
| `collectionSlug` provided but invalid | 400 |
| Empty Claude response | 400 |

## SEO & Humanization

System prompt enforces:
- Banned AI vocabulary: delve, elevate, unlock, transform, empower, navigate, foster, leverage, seamless, tailored, robust, groundbreaking, cutting-edge, state-of-the-art, innovative, comprehensive, revolutionize
- Active voice, specific claims, varied sentence lengths
- Short paragraphs (2-4 sentences), `##` headers for long-form content
- Semantically related terms woven in naturally (LLM SEO)
- Language: English or Bahasa Indonesia based on current locale

The `humanize()` function (shared with the SEO plugin) further strips AI vocabulary from the output and removes filler openers.

---

## Edge Cases

| Case | Handling |
|------|---------|
| Expand/Rewrite/Summarize with no selection | Generate button disabled + warning banner |
| `selectedText` > 4000 chars | Truncated before sending to Claude |
| No `docId` (unsaved doc) | Skip doc fetch; proceed with prompt-only context |
| Empty Claude response | 400 error; panel shows "Empty response" message |
| Panel closed mid-request | `AbortController` cancels the fetch |
| `ANTHROPIC_API_KEY` missing | 503 response; panel shows error |
| Generation > 8s | "Still generating…" message shown |
| Global document (no `collectionSlug`) | Skip doc fetch; proceed without doc context |

## Configuration

Added to `src/payload.config.ts`:

```typescript
import { AiContentFeature } from './features/aiContent/feature.server'

editor: lexicalEditor({
  features: ({ defaultFeatures }) => [
    ...defaultFeatures,
    AiContentFeature(),
  ],
}),
```

This applies the feature to all collections and globals that use the global `lexicalEditor` config.
